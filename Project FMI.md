Statement of Analysis

The empirical analysis evaluates the equity share price performance, risk, and return of the four selected IT companies using historical daily stock-price data. The major measures considered are Average Daily Return, Standard Deviation, Cumulative Return, and Beta Coefficient.

Interpretation

Infosys recorded the highest average daily return (0.6293%) and cumulative return (8.8947%), but it also had the highest standard deviation (2.02%), indicating comparatively greater price volatility.
Wipro generated an average daily return of 0.5829% and cumulative return of 8.3094%, while showing the lowest standard deviation (1.5466%) among the four companies.
TCS showed a relatively moderate return profile, with an average daily return of 0.2783%, cumulative return of 3.785%, and standard deviation of 1.6369%.
Tech Mahindra had an average daily return of 0.1966% and cumulative return of 2.7904%. Its beta of -0.8140indicates that, in the dataset's calculation, its returns moved inversely relative to the market benchmark.
Beta measures the stock's sensitivity to market movements. A beta above 1 generally indicates greater systematic sensitivity than the market, while a beta below 1 indicates lower sensitivity.
Overall Statement

The empirical results demonstrate that return and risk vary considerably across the selected IT stocks. The analysis shows that higher returns are not necessarily associated with proportionately higher volatility. For example, Wipro has a relatively high return with the lowest standard deviation, whereas Infosys has the highest return but also the highest volatility. Therefore, from the investors point of view, it needs to consider both return and risk, rather than evaluating stock performance solely based on price appreciation or returns.
